Entrada, processamento e saída

Programar é organizar instruções para que um computador resolva um problema. Um programa recebe dados, processa esses dados e apresenta um resultado.

EntradaPreço e quantidade
ProcessamentoPreço × quantidade
SaídaValor total
1

Entrada são os valores que o programa recebe. Neste exercício: 53.99 e 8.

2

Processamento é a operação realizada. Precisamos multiplicar o valor pela quantidade.

3

Saída é o resultado mostrado: 431.92.

Entenda cada comando

Vamos traduzir o código para linguagem comum

const

Cria um espaço para guardar uma informação que não será trocada durante este exercício.

valorPorServico

É o nome dado ao espaço que guarda o valor 53.99.

=

Atribui um valor. Leia como: “recebe”.

*

É o operador de multiplicação em JavaScript.

total

Guarda o resultado do cálculo.

console.log(total)

Mostra no console o valor guardado em total.

const total = valorPorServico * quantidade;

Tradução: crie uma informação chamada “total” e guarde nela o valor do serviço multiplicado pela quantidade.
