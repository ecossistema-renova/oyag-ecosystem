Trilha de aprendizagem

Uma formação em níveis, do primeiro código à construção de sistemas.

Nível 1 — Fundamentos

Lógica, variáveis, operadores, decisões e primeiros algoritmos.

Nível 2 — JavaScript

Funções, arrays, objetos e resolução estruturada de problemas.

Nível 3 — Web

HTML, CSS, DOM e interação com páginas reais.

Nível 4 — Git & GitHub

Versionamento, branches, commits e fluxo de projeto.

Nível 5 — APIs

Integrações, requisições assíncronas e consumo de dados.

Níveis avançados

Banco de dados, autenticação, segurança, arquitetura, pagamentos e projeto final.

Perguntas frequentes

Posso testar antes de pagar?

Sim. A OYAG Academy oferece uma experiência gratuita para você conhecer a metodologia antes de avançar para níveis pagos.

Como funciona a liberação dos níveis?

O conteúdo é liberado por progressão. Após concluir os requisitos de um nível, você pode contratar o próximo e continuar sua formação.

Preciso saber programação antes de começar?

Não. A trilha começa pelos fundamentos e foi estruturada para quem está iniciando.
